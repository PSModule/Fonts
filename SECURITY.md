# Security policy

## Supported versions

Security fixes target the latest Fonts release and the current `main` branch.
Fixes are not backported to older module versions. The module's Windows PowerShell 5.1 compatibility commitment is
documented in [CONTRIBUTING.md](CONTRIBUTING.md#powershell-51-compatibility-exception).

## Reporting a vulnerability

Do not disclose a suspected or confirmed vulnerability through a public issue, pull request, discussion, or other
public channel.

Use [private vulnerability reporting](https://github.com/PSModule/Fonts/security/advisories/new) in this repository's
**Security** tab when it is available. If that option is unavailable, email
[security@psmodule.io](mailto:security@psmodule.io).

Use the same private routes to report accidentally exposed sensitive information, credentials, secrets, and weak or
unsafe security controls or configurations.

Include the affected version or commit, the vulnerability and its impact, steps to reproduce it, and any proof of
concept or suggested mitigation. PSModule handles reports privately, investigates them, and coordinates remediation
and disclosure with the reporter.
