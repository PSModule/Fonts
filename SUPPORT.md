# Support

For help with Fonts:

1. Read the [README](README.md), [module documentation](https://psmodule.io/Fonts/), and PowerShell command help.
2. Search [existing issues](https://github.com/PSModule/Fonts/issues) for a known answer.
3. Open an issue in this repository for a public question, bug report, or feature request.

Include the module and PowerShell versions, operating system, expected and actual behavior, reproduction steps,
and sanitized logs. Remove credentials, personal information, and other secrets before posting.

Private support matters go to [support@psmodule.io](mailto:support@psmodule.io).

## Sensitive reports

Report security vulnerabilities through the private routes in the [security policy](SECURITY.md).
Report community conduct concerns through the private route in the [code of conduct](CODE_OF_CONDUCT.md).
To propose a change, follow the [contribution guide](CONTRIBUTING.md).
