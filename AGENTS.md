# Agent guidance

Fonts is a PowerShell module for listing, installing, and uninstalling fonts on Windows, Linux, and macOS.

Read [README.md](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md), then follow the canonical
[Process-PSModule guidance](https://psmodule.io/Process-PSModule/), including its
[repository standard](https://psmodule.io/Process-PSModule/reference/repository-standard/) and
[PowerShell module standard](https://psmodule.io/Process-PSModule/reference/powershell-module-standard/).

The approved [PowerShell 5.1 compatibility exception](CONTRIBUTING.md#powershell-51-compatibility-exception)
takes precedence over the framework's latest-LTS-only policy. Follow the contribution guide's test-isolation rules
to keep local checks away from real font directories and registry entries.
